# sport_orient_lottery
Десктопное Windows-приложение для проведения лотереи по результатам соревнований. Поддерживает загрузку JSON-файлов с результатами из систем SportOrga и WinOrient, фильтрацию участников по группам и проведение лотереи как среди всех участников, так и только среди призёров (1–3 места).
